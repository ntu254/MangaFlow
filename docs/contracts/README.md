# MangaFlow Contracts

## MVP Boundary

MangaFlow's MVP is an internal manga production and publishing workflow.
Public catalog, personal library, chapter reader, and reading-progress behavior
is not part of the MVP.

## Contract Requirements

Each product contract must define:

- Scope
- Out of scope
- Actors
- Business rules
- API surface
- Acceptance criteria
- Validation

Global invariants in `main.md` and exclusions in
`docs/product/out-of-scope.md` apply to every feature contract.
