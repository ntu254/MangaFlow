# UI Contract: Editorial Board UI

## Applies To

```txt
Board Dashboard
Series Approval Queue
Series Summary Review
Vote Screen
Ranking Table
Ranking Import
At-Risk Series
Tie-break Queue
Decision History
```

## Required Components

```txt
MFCard
MFBadge
MFButton
VoteCard
DecisionBadge
RankingTable
AtRiskBadge
ReviewDecisionBar
```

## Rules

```txt
Board pages should focus on summary, not page-level production detail.
Vote result must show counts clearly.
Tie-break must be visually separated for Board Chair.
Ranking import must validate readerScore 1–10.
At-risk decisions require confirmation.
```

## Done Criteria

```txt
[ ] Vote options are clear.
[ ] Vote summary is visible.
[ ] Board Chair tie-break state is clear.
[ ] Ranking table uses consistent badge/status UI.
[ ] At-risk actions have confirmation.
```
