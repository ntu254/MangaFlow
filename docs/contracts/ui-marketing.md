# UI Contract: Marketing / Landing UI

## Applies To

```txt
Landing Page
Marketing Navbar
Hero Section
Creative Pipeline
Role View Section
Footer
```

## Required Components

```txt
MarketingNavbar
MarketingFooter
HeroSection
HeroWorkspacePreview
CreativePipeline
RoleViewSection
MFButton
MFCard
```

## Rules

```txt
Use floating pill navbar.
Use large hero typography.
Use pastel background and white cards.
Use workflow preview mockups.
Use role tabs for Mangaka/Assistant/Editor/Board.
No dark landing theme.
No heavy gradient.
```

## Done Criteria

```txt
[ ] Hero has clear CTA.
[ ] Pipeline communicates workflow.
[ ] Role section uses reusable tab/panel components.
[ ] Footer matches style.
[ ] Mobile layout works.
```

## Validation

- Uses `MarketingNavbar`, `MarketingFooter`, `MFButton`, `MFCard`, and shared marketing components.
- Landing content presents production workflow, roles, review, board approval, and readiness.
- Uses design tokens for color, radius, shadow, and spacing.
- Mobile layout and keyboard focus are acceptable.
- UI review checklist passes.
