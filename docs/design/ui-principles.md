# UI Principles

MangaFlow uses a clean pastel creative SaaS aesthetic.

## Style

- Fresh
- Bright
- Pastel
- Creative
- Studio-oriented
- Not dark technology theme

## Colors

- Primary Purple: `#9065d5`
- Pink Purple: `#e560bc`
- Rose Pink: `#ff7196`
- Coral Orange: `#ff9971`
- Warm Yellow: `#ffc95e`
- Soft Lime: `#f9f871`

## Rules

- No dark theme as default.
- No heavy gradients.
- Use white cards.
- Use large radius.
- Use soft purple shadow.
- Keep work/art as focus.
