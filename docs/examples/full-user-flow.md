# Example Full User Flow

## Series approval

1. Admin creates accounts.
2. Mangaka logs in.
3. Mangaka creates Series "Shadow Ink".
4. Mangaka uploads `shadow-ink-proposal-v1.pdf`.
5. Mangaka submits to Editor.
6. Editor requests revision.
7. Mangaka uploads `shadow-ink-proposal-v2.pdf`.
8. Editor forwards to Board.
9. Board votes approve.
10. Series status becomes APPROVED.

## Production

1. Mangaka creates Chapter 1.
2. Uploads 20 pages.
3. Creates bubble regions.
4. Adds Assistant A to Production Team.
5. Assigns translation task for Page 5, with Page 4 and 6 as context.
6. Assistant submits translated text.
7. Mangaka approves.
8. Editor final approves.
9. Payroll is calculated.
