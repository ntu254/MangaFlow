# Feature List

## Product boundary

The MVP is an internal production workflow system. Public manga catalog,
personal library, chapter reader, and reading-progress features are excluded.

## MVP

- Custom auth
- Admin user management
- Task type configuration
- Series creation
- Initial manuscript upload
- Editor manuscript review
- Board voting and tie-break
- Chapter approval gate
- Page upload and file variants
- Page workspace
- Region rectangle creation
- Production Team management
- Task assignment
- Assistant Task Workspace
- Submission
- Mangaka review
- Editor final approval
- Comment resolution
- Publication readiness
- Ranking import and calculation
- At-risk decision
- Payroll tracking
- AI bubble detection/whitening
- Bubble translation workflow
- Notifications
- Role dashboards

## SHOULD

- Google OAuth
- Audit log UI
- Export payroll summary
- Calendar view for publication
- Compare page/manuscript versions

## FUTURE

- Public manga catalog and chapter reader
- Personal manga library and reading progress
- Public self-registration
- Real payment integration
- Mobile apps
- Polygon/free-draw annotation
- Layer management
- Clip Studio support
- AI panel/character/background detection
- Realtime collaborative workspace
