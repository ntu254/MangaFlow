# MangaFlow Overview

## Product Purpose

MangaFlow is a web application for managing manga creation and publishing work
from early manuscript submission through production tasks, review, board
approval, ranking, publication decisions, and assistant payroll.

The product replaces fragmented chat, drive folders, spreadsheets, and manual
status tracking with one role-aware workspace.

## Primary Outcomes

- Mangaka can create series, submit manuscripts, upload chapters and pages,
  annotate work areas, assign tasks, review assistant submissions, and track
  progress.
- Assistants can see assigned work, understand region-level requirements,
  submit versions, respond to revisions, and track approved earnings.
- Editors can review manuscripts and pages, leave comments, approve work, and
  prepare publication decisions.
- Editorial board members can vote on series, review ranking inputs, and make
  final publication or cancellation decisions.
- Admins can manage users, roles, operational settings, task rates, and system
  visibility.

## Current Stakeholders

- Admin
- Mangaka
- Assistant
- Tantou Editor
- Editorial Board

## MVP Outcome

The MVP proves one complete production flow:

1. User signs in with Google.
2. Mangaka creates a series.
3. Mangaka uploads a manuscript.
4. Editor reviews the manuscript.
5. Mangaka creates a chapter and uploads pages.
6. Mangaka annotates page regions and assigns tasks.
7. Assistant submits work.
8. Mangaka reviews the submission.
9. Editor gives final approval.
10. Board votes and ranking is tracked.
11. Assistant payroll can be calculated from approved task work.

## Current Non-Goals

- No staging environment is required for MVP.
- No preview environment is required for MVP.
- Custom domains are optional.
- Advanced AI training, model management, and post-MVP analytics are outside
  the first implementation slice.
- Product source specs are input references, not the ongoing operating plan.
