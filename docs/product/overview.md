# Product Overview

## Product name

MangaFlow — Manga Creation Workflow and Publishing Management System.

## Product purpose

MangaFlow manages the production workflow of manga studios from initial series proposal to publication, ranking, and payroll tracking.

## Product boundary

The MVP is production-only. It supports internal studio users and editorial
workflows; it is not a public manga catalog, personal library, chapter reader,
or reading-progress product.

## Core actors

- Admin
- Mangaka
- Assistant
- Tantou Editor
- Editorial Board
- Board Chair

## Core workflow

```txt
Admin creates users
→ Mangaka creates Series
→ Mangaka uploads initial Manuscript
→ Tantou Editor reviews
→ Editorial Board votes
→ Series approved
→ Mangaka creates Chapter
→ Mangaka uploads Pages
→ Mangaka/Editor creates Regions
→ Mangaka/Editor assigns Tasks
→ Assistant works and submits
→ Mangaka reviews
→ Editor final approves
→ Chapter readiness check
→ Publication
→ Ranking import
→ At-risk decision
→ Payroll tracking
```

## MVP promise

MVP must prove that MangaFlow can manage creative production with role-based access, page/region tasks, review chains, publication readiness, and ranking/payroll management.
