# Problem Statement

Manga teams currently rely on many disconnected tools for:

- Sending manuscript files
- Reviewing pages
- Assigning work to assistants
- Tracking revisions
- Resolving comments
- Preparing editorial decisions
- Tracking ranking data
- Calculating assistant earnings

This causes:

- Missed deadlines
- Confusion over which page/version is current
- Weak visibility for Editors and Board
- Inconsistent review process
- Poor assistant payment tracking
- Risk of leaking unpublished pages

MangaFlow solves this by centralizing workflow, permissions, files, comments, tasks, approvals, ranking, and payroll.
