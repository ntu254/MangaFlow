# Users and Roles

## Admin

Manages system users, roles, board members, task types, task rates, storage, audit logs, and system health.

## Mangaka

Creates series, uploads manuscripts, creates chapters/pages after approval, manages production team, assigns tasks, reviews submissions, and confirms payroll.

## Assistant

Receives tasks, works in Task Workspace, views assigned page/region and selected context pages, submits results, and tracks earnings.

## Tantou Editor

Reviews manuscript, forwards series to Board, creates comments, final approves tasks/pages/chapters, resolves comments, and checks publication readiness.

## Editorial Board

Votes on series approval, decides weekly/monthly publication direction, imports ranking data, reviews at-risk series, and decides continue/warning/cancel.

## Board Chair

Has all Board permissions and resolves tie votes.
