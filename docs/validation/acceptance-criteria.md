# Acceptance Criteria

## Product-level done

MangaFlow MVP is accepted when:

- Admin can create users and roles.
- Mangaka can submit Series proposal.
- Editor can review and forward to Board.
- Board can approve/reject/needs revision.
- Chapter creation is blocked until Series approval.
- Pages can be uploaded and variants generated.
- Regions can be created.
- Assistant must be in Production Team before assignment.
- Assistant can access only Task Workspace.
- Submission passes Mangaka then Editor review.
- Comments block publication until resolved.
- Ranking formula works.
- Payroll is calculated after Editor approval.
- Notifications are generated for key events.
